# ClickUp MCP Server

Open-source [Model Context Protocol](https://modelcontextprotocol.io) server for [ClickUp](https://clickup.com). Manage tasks, lists, and projects directly from AI agents like Claude.

> This project was generated by Claude Code (claude-opus-4-6-20250616).

## Features

**17 tools** covering the core ClickUp workflow:

| Category | Tools |
|----------|-------|
| Navigation | `get_user`, `list_workspaces`, `list_spaces`, `list_folders`, `list_lists`, `get_list` |
| Tasks | `get_task`, `list_tasks`, `search_tasks`, `create_task`, `update_task`, `delete_task` |
| Comments | `get_task_comments`, `create_task_comment` |
| Checklists | `create_checklist`, `create_checklist_item`, `update_checklist_item` |

- Full task CRUD with priorities, assignees, tags, due dates, and markdown descriptions
- Search across workspaces with filters (status, assignee, tags, date ranges)
- Checklist management (create, add items, mark complete)
- Task comments (read and create)
- Custom field visibility on lists

## Setup

### 1. Get your ClickUp API token

Go to **ClickUp Settings > Apps > API Token** and generate a personal token (starts with `pk_`).

### 2. Set the token in your shell environment

Add to your shell profile so it's available across sessions:

**fish** (`~/.config/fish/config.fish`):
```fish
set -Ux CLICKUP_API_KEY pk_your_token_here
```

**bash/zsh** (`~/.bashrc` or `~/.zshrc`):
```bash
export CLICKUP_API_KEY=pk_your_token_here
```

### 3. Build and register

```bash
git clone https://github.com/scrapeer/clickup-mcp-server.git
cd clickup-mcp-server
make setup
```

This installs dependencies, builds the server, and registers it with Claude Code. Your token stays in your shell environment, not in config files.

`make setup` defaults to Claude Code. For other tools:

| Tool | Register | Unregister |
|------|----------|------------|
| [Claude Code](https://claude.com/claude-code) | `make register-claude` | `make unregister-claude` |
| [OpenAI Codex CLI](https://github.com/openai/codex) | `make register-codex` | `make unregister-codex` |
| [Google Gemini CLI](https://github.com/google-gemini/gemini-cli) | `make register-gemini` | `make unregister-gemini` |

### Manual registration

If you prefer to register manually or use a different MCP client:

**Claude Code:**
```bash
claude mcp add clickup -s user -t stdio \
  -e CLICKUP_API_KEY='${CLICKUP_API_KEY}' \
  -- node /path/to/clickup-mcp-server/dist/index.js
```

**OpenAI Codex CLI:**
```bash
codex mcp add clickup \
  --env CLICKUP_API_KEY='${CLICKUP_API_KEY}' \
  -- node /path/to/clickup-mcp-server/dist/index.js
```

**Google Gemini CLI:**
```bash
gemini mcp add -s user \
  -e CLICKUP_API_KEY='${CLICKUP_API_KEY}' \
  clickup node /path/to/clickup-mcp-server/dist/index.js
```

**Any other MCP client** (Cursor, VS Code, Windsurf, etc.) — point it at `node /path/to/clickup-mcp-server/dist/index.js` as a stdio server with `CLICKUP_API_KEY` in the environment.

## Usage

Once configured, Claude can manage your ClickUp tasks naturally:

- "Show me my ClickUp tasks" — navigates hierarchy, lists tasks
- "Create a task called 'Fix login bug' in the Sprint list" — creates with context
- "Mark task 8ckjp5 as complete" — updates status
- "What's the status of my high-priority tasks?" — searches with filters
- "Add a comment to task 8ckjp5" — posts comments

## Environment Variables

| Variable | Required | Description |
|----------|----------|-------------|
| `CLICKUP_API_KEY` | Yes | Personal API token (`pk_...`). Set in your shell, not in config files. |
| `CLICKUP_API_BASE_URL` | No | API base URL (default: `https://api.clickup.com/api/v2`) |

## ClickUp Hierarchy

The ClickUp data model is hierarchical:

```
Workspace > Space > Folder (optional) > List > Task
```

Navigation tools follow this hierarchy. Start with `clickup_list_workspaces` and drill down.

## Rate Limits

ClickUp enforces rate limits per API token:

| Plan | Limit |
|------|-------|
| Free / Unlimited / Business | 100 req/min |
| Business Plus | 1,000 req/min |
| Enterprise | 10,000 req/min |

For interactive AI usage, the free tier limit is more than sufficient.
